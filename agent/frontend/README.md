# Frontend Documentation Index

- Статус: draft
- Назначение: индекс общих frontend-правил.

Этот раздел содержит документы о том, как вести frontend-разработку. README
остается индексом: он содержит только карту документов и условия их чтения.

## Документы

| Документ | Когда читать |
|---|---|
| [view-component-rules.md](view-component-rules.md) | Когда задача затрагивает React-компоненты, `view`-слой, структуру каталогов компонента, импорты через `index.ts`, вложенность компонентов или вынос части JSX в отдельный компонент. |
| [react-component-code-rules.md](react-component-code-rules.md) | Когда задача затрагивает код внутри React-компонента: порядок объявления, props, local helpers/hooks, derived values, handlers, effects, JSX, render callbacks или признаки перегруза компонента. |

## Как Добавлять Документы

- Новый набор правил добавляй отдельным файлом с названием по теме.
- README обновляй только как индекс: добавь ссылку и краткое условие чтения.
- Не добавляй в общий документ справку о пакетах, маршрутах или файлах
  приложения.
- Прикладные детали должны оставаться в локальной документации приложения.
